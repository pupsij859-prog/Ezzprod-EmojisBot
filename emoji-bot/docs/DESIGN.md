# EzzProd — дизайн-спека Mini App и бота (v1)

Документ для разработчика: по нему можно верстать без догадок. Единицы — CSS px при вьюпорте **390×844**; всё обязано работать от **360 до 430** по ширине и на десктопе (~**420×700**, колонка по центру). Весь интерфейс — **русский, строчные буквы**. Бренд пишется **EzzProd** (в тексте), знак — монограмма **«ep»**.

Ассеты лежат в `webapp/assets/` (карта — в §1). Каждый SVG самодостаточен: без внешних ссылок и шрифтов, текст в них переведён в формы.

Оглавление: 0 концепция · 1 бренд и файлы · 2 токены · 3 типографика · 4 motion · 5 компоненты · 6 экраны · 7 онбординг · 8 заглушки шаблонов (SVG) · 9 баннер бота · 10 микрокопи, доступность, чек-лист.

## 0. Концепция

**Идея бренда — «окно в горы».** Заказчик прислал аватарку: жирные округлые строчные «ep», как стекло, сквозь которое проглядывает яркий заснеженный хребет, а вокруг всё затемнено — сумеречные горы, синяя дымка, тёмная трава, синица с жёлтой грудкой. Интерфейс продолжает этот образ:

- фон — глубокий **сине-стальной** (не чистый чёрный), сверху — холодное **ледяное свечение**;
- «стеклянные» плавающие панели (blur) — шапка, таб-бар, панель выбора;
- **ледяной** (светло-голубой) цвет — только для главного действия, выбора и фокуса;
- оливковый и золотой — точечные акценты (успех, Stars/pro), не больше пары мест на экран.

**Единственная ставка (то, что должны запомнить):** широкие строчные заголовки Unbounded + ледяное свечение сверху + глиф **✦** как «валюта» и мотив продукта (баланс, загрузка, онбординг, карточки). Всё остальное намеренно тихое.

**Принципы**

1. Один главный CTA на экран. Он единственный ледяной (или ярко-синий, если это покупка).
2. Плавающее = стекло (blur + тонкая светлая кайма). Лежащее на странице = плоская поверхность (surface). Не смешивать.
3. Свечение только сверху экрана. Никаких градиентных «пятен» по карточкам.
4. Состояние всегда читается без цвета: выбрано = кольцо + галочка; disabled = плоская тёмная заливка + приглушённый текст; загрузка = спиннер/скелетон.
5. Движение отвечает на действие пользователя (открыл, выбрал, подтвердил). Само по себе двигается только прогресс и один входной «выход» на экране-приветствии.
6. Все числа с `font-variant-numeric: tabular-nums`; все склонения через `plural()`.

**Что исправляем относительно референса**

| Недочёт референса | Решение у нас |
|---|---|
| «3 генераций за друга» | `plural(n, 'генерация','генерации','генераций')`: «3 генерации за друга» |
| BackButton то есть, то нет | Telegram BackButton виден **всегда**, когда открыт любой оверлей, шторка, модалка или подэкран; скрыт только на корне вкладок (§5 C11–C14) |
| «−10%» не сходится с ценой | Показываем разбор цены: «30 × 9 ⭐ = 270», «скидка −10% (−27)», «итого 243 ⭐» (числа условные, настоящие — из `GET /pricing`) |
| Голый Telegram ID в ссылке | Ссылка `?start=ref_<8 символов>` — код непрозрачный |
| «pro» без объяснения | Замок + экран «что даёт pro» и как его открыть (§6 S06) |
| Не понять disabled у серо-голубых кнопок | Включённая — ледяной градиент со свечением, выключенная — плоская тёмная с серым текстом (§5 C18) |
| «бесплатный · 1 пробный экспорт — 1 генерация» дублирует баланс | Строка тарифа показывает только тариф; проба и подарок — на отдельном экране «бесплатно и проба» |

### 1.3 Иконки (`icons.svg`)

Подключение: `<svg class="icon" aria-hidden="true"><use href="assets/icons.svg#i-grid"/></svg>`. Цвет — `currentColor`. Размеры 16/18/20/22/24 (CSS `width/height`), штрих 1.75 при 24 px (масштабируется вместе с иконкой — штрих тоньше/толще при другом размере допустим, не подгонять). Сам спрайт задаёт `fill:none; stroke:currentColor; stroke-width:1.75; round caps/joins` на `<symbol>`, отдельный CSS не нужен.

Минимальный CSS: `.icon{width:24px;height:24px;flex:none}`.

Набор: `grid box user chev-right chev-left close back plus minus sparkle copy check share star lock info help doc chat users upload palette trash play link crown`.
Дополнительно: `send` (самолётик — «открыть в telegram»), `gift`, `refresh` (повторить), и **сплошные** `grid-fill box-fill user-fill` (иконки таб-бара), `sparkle-fill` (глиф ✦), `star-fill` (Stars ⭐).

Назначение: `sparkle-fill` — баланс «✦ N», `star-fill` — цены в Stars (цвет `--brand-gold`), `crown` — pro/покупка, `lock` — закрытые функции, `chat` — поддержка, `doc` — документы, `users` — рефералка, `play` — «как пользоваться», `palette` — цвета, `upload` — логотип, `check` — выбор/готово, `copy` — копирование ссылки.

### 2.5 Шкала отступов

4-pt: 2 · 4 · 6 · 8 · 10 · 12 · 16 · 20 · 24 · 32 · 40 · 56. Боковое поле экрана — **16**. Между секциями — **24**, между меткой секции и группой — **8**, между карточками подряд — **10–12**, внутри карточки — **16**.

### 2.6 Тени и blur

- **Стекло** (шапка-чип, категория-пилюля, пагинация, selection bar, tab bar): `background:var(--glass); backdrop-filter:var(--blur-glass); border:1px solid var(--line-strong); box-shadow:var(--shadow-float)`. Фолбэк: `@supports not (backdrop-filter:blur(1px)){background:var(--glass-solid)}`.
- **Шторка:** `box-shadow:var(--shadow-sheet)`; верхние углы r=28.
- **Scrim:** `background:var(--scrim); backdrop-filter:var(--blur-scrim)`.
- **Кнопки:** основная — `--shadow-btn`; покупка — `--shadow-buy`; disabled — тени нет.
- **Выбранная карточка:** `--ring-selected`.

### 2.7 Слои (z-index)

`0` ambient-свечение → `1` контент → `15` fade-подложки → `20` верхняя панель → `30` панель выбора → `40` таб-бар → `100+10·i` оверлеи (scrim; `105+10·i` — сама панель) → `400` онбординг → `500` тост. Каждый новый оверлей (шторка, модалка, экран) — на ступень выше предыдущего.

## 3. Типографика

**Заголовки — Unbounded** (Google Fonts, есть кириллица), **текст — Inter** (кириллица есть). Широкий жирный Unbounded даёт тот же характер, что у референса, и перекликается с круглыми жирными «ep».

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Unbounded:wght@500;600;700;800&family=Inter:wght@400;500;600;700&display=swap">
```
`display=swap`; подмножества (cyrillic/latin) Google отдаёт сам по `unicode-range`. Фолбэк-стеки заданы в `--font-display` / `--font-text`; на время загрузки `font-synthesis:none`. Если мини-апп должен работать при закрытом Google — положить `woff2` в `webapp/assets/fonts/` и подключить через `@font-face` с теми же именами (необязательно для v1).

### 3.2 Правила

- **Всё строчными.** Пишем строчными в исходнике; на `h1–h3`, кнопки, метки секций и бейджи дополнительно `text-transform:lowercase` как страховка. **Не** применять к пользовательскому тексту (имя, @username, текст на эмодзи, название пака/стиля, hex). Исключение — имя бренда **EzzProd** в тексте.
- Заголовки Unbounded: `text-wrap:balance`, максимум 2 строки, длинные слова не переносить (`hyphens:manual`).
- Пользовательские строки: `overflow-wrap:anywhere`; в списках — одна строка с `text-overflow:ellipsis`.
- Числа (баланс, цены, счётчики, hex): `font-variant-numeric:tabular-nums`.
- Длина строки абзаца ≤ 36 em (в 358-px колонке это ≈ 40 знаков при 15–16 px).
- Склонения: `plural(n, one, few, many)`: `n%10==1 && n%100!=11` → one; `n%10∈2..4 && n%100∉12..14` → few; иначе many. Слова: *генерация/генерации/генераций*, *стикер/стикера/стикеров*, *пак/пака/паков*, *друг/друга/друзей*; «эмодзи» **не склоняется**.
- Деньги: `180 ⭐` (число + неразрывный пробел `U+00A0` + иконка `star-fill` золотая), никаких ₽.

## 4. Motion

Базовые токены — в §2.1. Принцип: **быстро на нажатие, плавно на появление, ничего лишнего самого по себе.**

| Событие | Что анимируем | Длительность | Easing | Детали |
|---|---|---|---|---|
| Нажатие (кнопки, карточки, строки, чипы) | `transform:scale(.97)` (кнопки .98; строки — только фон) | вниз `90ms`, вверх `180ms` | `--ease-out` | + смена фона/яркости (`filter:brightness(.92)`) |
| Выбор карточки шаблона | кольцо (`box-shadow`), фон-тинт, превью `scale(1.04)`; бейдж-галочка `scale(.4→1)` | кольцо `160ms`, галочка `240ms` | кольцо `--ease-out`, галочка `--ease-pop` | снятие выбора — обратно за `120ms`, без «овершута» |
| Появление панели выбора | `translateY(24px→0)` + `opacity 0→1` | `280ms` | `--ease-out` | исчезает за `180ms`, `--ease-in`; счётчик при изменении «подпрыгивает» `scale(1→1.08→1)` за `200ms` |
| Шторка (bottom sheet) | `translateY(100%→0)`; scrim `opacity 0→1` | открытие `380ms`, закрытие `260ms`; scrim `240ms` | открытие `--ease-out`, закрытие `--ease-in` | перетаскивание за ручку/шапку следует за пальцем 1:1; закрытие при сдвиге > 120 px или скорости > 0.6 px/мс, иначе возврат за `260ms` `--ease-out` |
| Модалка по центру | `scale(.94→1)` + `translateY(12px→0)` + `opacity` | открытие `280ms`, закрытие `180ms` | `--ease-out` / `--ease-in` | фон под ней: scrim + `blur 12px` |
| Полноэкранный оверлей (рефералка, покупка, пак готов) | `translateY(16px→0)` + `opacity` | `320ms` / закрытие `200ms` | `--ease-out` / `--ease-in` | |
| Переключение вкладок | кросс-фейд + сдвиг `translateX(±16px→0)` в сторону новой вкладки | `220ms` | `--ease-out` | таб-бар: подсветка активной «переезжает» (`transform` по x) за `240ms` `--ease-io`; иконка активной — `scale(1→1.12→1)` `--ease-pop` `240ms` |
| Сегмент «эмодзи / стикеры» | ползунок `translateX` | `240ms` | `--ease-io` | содержимое под сегментом — fade `120ms` |
| Тост | вход: `translateY(-16px→0)`+`opacity`; пауза 2400 мс (ошибка — 4000); выход: `opacity`+`translateY(-8px)` | вход `320ms`, выход `200ms` | `--ease-out` / `--ease-in` | при показе нового — предыдущий уходит сразу |
| Чип баланса при изменении | число: `translateY` смена + `scale(1→1.12→1)` у чипа | `220ms` | `--ease-pop` | |
| Копирование | иконка `copy → check` (кросс-фейд + `scale`) | `160ms`, держится 1500 мс | `--ease-out` | |
| Skeleton | диагональный блик `translateX(-100%→100%)` | `1400ms`, `infinite` | `linear` | |
| Прогресс-кольцо / бар | `stroke-dashoffset` / `width` | по данным; сглаживание `240ms` | `--ease-io` | этапы переключаются мгновенно, галочка этапа — `--ease-pop` `200ms` |
| Слайды инструкции | `translateX` трека (следует за пальцем), затем доводка | `360ms` | `--ease-out` | текст нового слайда: `opacity+translateY(12px→0)` `280ms`, задержка `60ms`; иллюстрация: `scale(1.04→1)` `360ms`; точки: ширина активной `6→18px` `240ms` `--ease-io` |
| Приветствие (один раз) | **единственный оркестрованный вход**: hero `scale(.96→1)+opacity` `500ms`; заголовок, лид, 3 преимущества, подарок, CTA — каскад с шагом `70ms` (`opacity+translateY(14px→0)`, `360ms`) | итого ≲ 1100 мс | `--ease-out` | |
| «Пак готов» | миниатюры пака появляются каскадом: `scale(.8→1)+opacity`, шаг `40ms` (макс. 12 штук, остальные сразу), `280ms` `--ease-pop`; галочка-орб `scale(.5→1)` `360ms` `--ease-pop` | | | |
| Лимит выбора | карточка «трясётся»: `translateX(0,−4,4,−3,0)` | `260ms` | `--ease-io` | + тост-предупреждение |

**`prefers-reduced-motion: reduce`** (обязательно):
- все `transform`-движения (сдвиги, масштабы, «овершут», тряска, параллакс иллюстраций, каскад welcome) отключаются; остаются **только** `opacity`-переходы ≤ `120ms`;
- шторка/модалка/оверлей появляются fade'ом за `120ms` (без сдвига), перетаскивание шторки пальцем остаётся (это прямое управление);
- слайды инструкции переключаются кросс-фейдом `120ms`;
- skeleton — статичный (`opacity:.7`), без блика;
- индикатор загрузки (спиннер) остаётся как функциональная обратная связь, но замедляется до `1.4s/оборот`;
- прогресс-кольцо/бар меняются без сглаживания;
- haptics не отключаем (они не визуальные).

```css
@media (prefers-reduced-motion: reduce){
  *,*::before,*::after{animation-duration:.01ms!important;animation-iteration-count:1!important;
    transition-property:opacity,background-color,color,border-color!important;transition-duration:.12s!important}
}
```

Формат: **размеры** → **состояния** (default / pressed / selected / disabled / loading, где применимо) → заметки. ### Общая раскладка приложения


## 7. Онбординг (ключевое требование заказчика)

Два шага при первом входе, затем только инструкция по запросу:

1. **Окно-приветствие** — один раз, тёплая встреча, что такое EzzProd, 3 преимущества, подарок, «поехали».
2. **Инструкция-карусель** — 5 слайдов с иллюстрациями. Показывается сразу после приветствия и **повторно открывается из профиля** («как пользоваться») — уже без приветствия.

## 8. Рецепт процедурных SVG-заглушек шаблонов

Цель — 319 шаблонов-заглушек, которые в сетке 3 колонки на тёмной карточке (≈ 112 px, превью ≈ 84 px) выглядят как «3D-наклейки», а не как заглушки. Рецепт **проверен**: на 42 образцах (14 форм × 10 палитр × разный текст) всё читается и выглядит единообразно; готовая эталонная реализация — §8.7.

### 8.1 Общее

- Эндпоинт: `GET /api/templates/{id}/preview.svg?text=&fill=&stroke=`; ответ `image/svg+xml; charset=utf-8`, `Cache-Control: public, max-age=86400, immutable`, `ETag` от (id, text, fill, stroke).
- `viewBox="0 0 256 256" width="256" height="256" fill="none"`. Контент вписан в поле 24…232; точка опоры (низ) ≈ y 232–244 (под ней тень).
- Параметры: `text` — до 12 знаков, экранировать XML; `fill`, `stroke` — `^[0-9a-fA-F]{6}$` (без `#`), иначе берём палитру шаблона (§8.3). `fill` = цвет корпуса, `stroke` = цвет обводки **и** лицевой грани текста — как «заливка / обводка» в шторке.
- Без `text` — подставляем `ezz`. Форма и палитра шаблона — детерминированы по индексу (§8.6). Никаких внешних ссылок, `<image>`, `@font-face`.

### 8.4 Как строится «3D» (порядок слоёв, снизу вверх)

Пусть `F` = fill, `S` = stroke; `deepF = darken(F,.55)`, `lightF = lighten(F,.38)`, `darkF = darken(F,.36)`, `lightS = lighten(S,.35)` (`lighten/darken` = смешивание с белым/чёрным).

| # | Слой | Как рисуется |
|---|---|---|
| 1 | **Тень на «земле»** | эллипс `cx128 cy244 rx78 ry8`, `#000`, `opacity .45`, `feGaussianBlur σ5` |
| 2 | **Экструзия (толщина)** | все части (кроме `line`) копией со сдвигом `translate(0, depth)` (depth = 9, у монеты 16): заливка и обводка `deepF`, `stroke-width 8`, `round` |
| 3 | **Корпус** | `main`: заливка `linearGradient` в абсолютных координатах `(52,24)→(206,236)`: `0% lightF → 42% F → 100% darkF`; обводка `S`, `stroke-width 7`, `stroke-linejoin round` (скругляет все углы). `accent`: градиент `lighten(S,.5)→S→darken(S,.3)`, обводка `darken(S,.5)` ширины 4 |
| 4 | **Внутренняя тень** | в `clipPath` по всем `main`: те же контуры со штрихом `deepF` шириной 26, `opacity .5`, `feGaussianBlur σ7`, смещение `translate(−5,−8)` (свет слева-сверху) |
| 5 | **Блик** | в том же `clipPath`: наклонный эллипс (`gloss=(cx,cy,rx,ry,rot)` из таблицы формы), заливка `linearGradient` белый `opacity .62 → 0` сверху вниз |
| 6 | **Искра** | круг `r5` белый `opacity .8`, blur σ1, в левом верхнем краю блика |
| 7 | **Текст** | см. §8.5 |

Если пользователь задал `fill`/`stroke`, все производные цвета пересчитываются от них. Контраст текста гарантирует тёмная обводка букв (`deepF`, §8.5): читается и на светлом корпусе.

### 8.5 Текст-бренд

- Шрифт: `font-family:'Arial Black','Segoe UI Black','Helvetica Neue',Arial,sans-serif; font-weight:900` — системный (в `<img>`-SVG веб-шрифты недоступны). Разница ширины шрифтов на устройствах нивелируется атрибутами `textLength` (ширина **рассчитана на сервере**) и `lengthAdjust="spacingAndGlyphs"`.
- **Размер от длины.** `fs = min(76, 76 · W / width(text, 76))`, где `width()` — реальная ширина строки в Pillow (`ImageFont.truetype('ariblk.ttf').getlength`), `W` — ширина «таблички» формы (§8.2). Короткие слова получают до 76, длинные ужимаются.
- **Нижний предел:** `fs ≥ 18`. Если не помещается — строка **укорачивается справа** (без многоточия) до тех пор, пока не станет `fs ≥ 18`. На узких формах (звезда, молния, ракета, подарок) длинный бренд превращается в начало слова — это нормально.
- **Позиция:** `text-anchor:middle`, `x = cx`, `y = cy + fs·0.36` (оптический центр строчных); группа повёрнута `rotate(rot cx cy)`.
- **Слои текста:** (а) тень — копия со сдвигом `translate(0, fs·.09)`, заливка и штрих `deepF`, `stroke-width = max(2.5, fs·.11)`, `opacity .9`; (б) лицо — заливка `linearGradient` сверху вниз `#fff → lightS`, штрих `deepF` шириной `0.8 × stroke-width` с `paint-order:stroke` (штрих — под заливкой), `stroke-linejoin:round`.

```python
def radial_glow(size, center, radius, color, alpha, power=1.8):
    """RGBA layer (size) with a soft radial glow (alpha falls off as (1-r)^power)."""
    d = int(radius * 2)
    g = Image.radial_gradient('L').resize((d, d), Image.BICUBIC)      # 0 at center -> 255 at edge
    g = g.point(lambda v: int(255 * alpha * max(0.0, 1 - min(1.0, v / 180.3)) ** power))   # 255 = corner, 180 = edge midpoint
    a = Image.new('L', size, 0)
    a.paste(g, (int(center[0] - radius), int(center[1] - radius)))     # paste clips at borders
    layer = Image.new('RGBA', size, color + (0,))
    layer.putalpha(a)
    return layer

def screen(base, layer):
    """Screen-blend an RGBA glow layer onto an RGB image."""
    rgb = layer.convert('RGB')
    a = layer.split()[3]
    lit = ImageChops.screen(base, rgb)
    return Image.composite(lit, base, a)

def vignette(img, strength=0.55):
    m = Image.radial_gradient('L').resize((int(W * 1.25), int(H * 1.5)), Image.BICUBIC)
    m = m.crop(((m.width - W) // 2, (m.height - H) // 2, (m.width - W) // 2 + W, (m.height - H) // 2 + H))
    m = m.point(lambda v: int(255 * (1 - strength * min(1.0, v / 180.3) ** 2.2)))      # 255 center -> darker edges
    return ImageChops.multiply(img, Image.merge('RGB', (m, m, m)))

def ep_mask(h):
    """Antialiased 'ep' mask of height h (x-height + descender). Geometry = crop space of the brand glyph."""
    k = 4
    s = h * k / (595 - 72.0)
    ox, oy = 72, 72
    wpx = int((980 - 72) * s) + 2
    hpx = int((595 - 72) * s) + 2
    m = Image.new('L', (wpx, hpx), 0)
    d = ImageDraw.Draw(m)
    def bb(x0, y0, x1, y1):
        return [(x0 - ox) * s, (y0 - oy) * s, (x1 - ox) * s, (y1 - oy) * s]
    # e
    d.ellipse(bb(72, 72, 510, 538), fill=255)
    d.ellipse(bb(195, 165, 385, 450), fill=0)
    d.rectangle(bb(197, 255, 500, 335), fill=255)
    d.rectangle(bb(383, 335, 540, 395), fill=0)
    # p
    d.rectangle(bb(532, 85, 652, 595), fill=255)
    d.ellipse(bb(580, 72, 980, 540), fill=255)
    d.ellipse(bb(652, 165, 862, 450), fill=0)
    return m.resize((wpx // k, hpx // k), Image.LANCZOS)

def ice_gradient(size):
    g = Image.linear_gradient('L').resize(size, Image.BICUBIC)
    return ImageOps.colorize(g, black=(255, 255, 255), mid=ICE_HI, white=ICE, midpoint=120)

def paste_ep(canvas, cx, top, h, opacity=1.0):
    m = ep_mask(h)
    if opacity < 1:
        m = m.point(lambda v: int(v * opacity))
    layer = ice_gradient(m.size)
    canvas.paste(layer, (int(cx - m.width / 2), int(top)), m)

def fit_size(font_path, text, target_width):
    """Font size at which `text` is `target_width` px wide (independent of the concrete font)."""
    f100 = ImageFont.truetype(font_path, 100)
    return round(100 * target_width / f100.getlength(text))

def spaced_text(draw, xy_center, text, font, fill, spacing):
    widths = [draw.textlength(ch, font=font) for ch in text]
    total = sum(widths) + spacing * (len(text) - 1)
    x = xy_center[0] - total / 2
    for ch, w in zip(text, widths):
        draw.text((x, xy_center[1]), ch, font=font, fill=fill, anchor='lm')
        x += w + spacing

# ---------------------------------------------------------------- backgrounds
def bg_photo(blur=7, bright=1.6, contrast=1.15):
    src = Image.open(AVATAR).convert('RGB')                                   # 640x568
    bg = src.resize((1280, 1136), Image.LANCZOS).crop((0, 300, 1280, 1020))   # 2x, window y=300..1020
    bg = bg.filter(ImageFilter.GaussianBlur(blur))
    bg = ImageEnhance.Brightness(bg).enhance(bright)
    bg = ImageEnhance.Contrast(bg).enhance(contrast)
    return ImageChops.multiply(bg, Image.new('RGB', (W, H), (205, 226, 255)))  # cold grade

def midpoint(seed, x0, x1, ymid, amp, rough=0.55, detail=7):
    rnd = random.Random(seed)
    n = 2 ** detail
    pts = [0.0] * (n + 1)
    step, a = n, amp
    while step > 1:
        half = step // 2
        for i in range(half, n, step):
            pts[i] = (pts[i - half] + pts[i + half]) / 2 + rnd.uniform(-1, 1) * a
        a *= rough
        step = half
    return [(x0 + (x1 - x0) * i / n, ymid + pts[i]) for i in range(n + 1)]

def bg_procedural(seed=3):
    HOR = 520                                                            # horizon y (sky is brightest here)
    g = Image.linear_gradient('L').resize((W, HOR), Image.BICUBIC)
    top = ImageOps.colorize(g, black=(9, 14, 24), mid=(24, 38, 58), white=(104, 138, 170), midpoint=125)
    sky = Image.new('RGB', (W, H), (104, 138, 170))
    sky.paste(top, (0, 0))
    d = ImageDraw.Draw(sky)
    rnd = random.Random(seed)
    for _ in range(110):                                                 # stars (upper half only)
        x, y = rnd.uniform(0, W), rnd.uniform(0, H * 0.45)
        r = rnd.uniform(.7, 1.7)
        c = int(rnd.uniform(160, 255))
        d.ellipse([x - r, y - r, x + r, y + r], fill=(c, c, 255))
    cl = Image.new('RGBA', (W, H), (0, 0, 0, 0))                         # soft clouds
    cd = ImageDraw.Draw(cl)
    for _ in range(8):
        cx, cy = rnd.uniform(.05, .95) * W, rnd.uniform(.12, .52) * H
        rx, ry = rnd.uniform(140, 320), rnd.uniform(10, 26)
        cd.ellipse([cx - rx, cy - ry, cx + rx, cy + ry], fill=ICE + (int(rnd.uniform(30, 55)),))
    cl = cl.filter(ImageFilter.GaussianBlur(16))
    land = Image.alpha_composite(sky.convert('RGBA'), cl)
    layers = [  # (ymid, amp, color) far -> near: lighter/bluer -> darker (aerial perspective)
        (455, 110, (72, 100, 132)), (520, 95, (52, 77, 106)),
        (592, 70, (36, 56, 81)), (655, 48, (24, 40, 60)), (704, 28, (13, 22, 36))]
    for i, (ym, amp, col) in enumerate(layers):
        poly = midpoint(seed * 10 + i, -10, W + 10, ym, amp, 0.58) + [(W + 10, H + 10), (-10, H + 10)]
        lay = Image.new('RGBA', (W, H), (0, 0, 0, 0))
        ImageDraw.Draw(lay).polygon(poly, fill=col + (255,))
        land = Image.alpha_composite(land, lay)
        land = Image.alpha_composite(land, radial_glow((W, H), (W / 2, ym + 90), 760, ICE, .07, 1.3))   # fog at ridge base
    return land.convert('RGB').filter(ImageFilter.GaussianBlur(2.2))

# ---------------------------------------------------------------- composition
def banner(variant='photo', out='banner.png'):
    import os
    if variant == 'photo' and not os.path.exists(AVATAR):
        variant = 'proc'                                              # automatic fallback
    bg = bg_photo() if variant == 'photo' else bg_procedural()

    # text scrim

    scrim = scrim.filter(ImageFilter.GaussianBlur(60))

    d = ImageDraw.Draw(img)
    for t, y in zip(lines, cy):

    rgb = img.convert('RGB')
    # brand mark + wordmark

if __name__ == '__main__':
```

### 10.3 Доступность

- Контраст: `--tx` и `--tx2` на `--s1` — AA (16:1 / 7.9:1); `--tx3` только для плейсхолдеров и disabled. Кнопки — §2.2.
- Зоны касания ≥ 44×44; видимый фокус везде (`--ring-focus`); порядок табуляции = визуальный; Esc закрывает верхний оверлей.
- Семантика: вкладки — `tablist`; карточки шаблонов — `checkbox`; шторка/модалки — `dialog aria-modal` + focus trap + возврат фокуса; тосты — `aria-live`; прогресс — `progressbar`; карусель — §7.2.
- Не передавать смысл одним цветом (выбор = кольцо **и** галочка; статус = текст **и** цвет).
- `prefers-reduced-motion` — §4. Масштаб текста до 200 %: контейнеры растут по высоте (никаких фиксированных высот у текстовых блоков, кроме кнопок/строк с `min-height`).
- Иллюстрации — `alt=""` (декор) с `aria-hidden`, смысл дублируется текстом слайда; маскот — `alt="грустный стикер с слезой"`.

### 10.4 Что разработчику важно не пропустить

1. **BackButton виден всегда на любом оверлее**, скрыт только на корне вкладок (единый стек, C11) + `disableVerticalSwipes()`, иначе свайп шторки закрывает апп.
2. Плавающие панели — `absolute` внутри `.app`, а не `fixed`: иначе на десктопе (420×700) всё уезжает. Нижний отступ контента считать из `--dock-h`.
3. Все плюрали — `plural()`; «эмодзи» не склоняется; «3 генерации», не «3 генераций».
4. Выбор шаблонов живёт **вне** страницы/категории (Map), лимиты 200/120.
5. Disabled-кнопка = плоская тёмная с серым текстом (не «другого цвета»), и тап по ней объясняет причину тостом.
6. Цена и скидки — только из `GET /pricing`; в покупке показывать разбор «N × цена → скидка → итого», валюта — ⭐ (иконка `star-fill`, золото), без ₽.
7. Pro у free: замок + экран S06 с объяснением «как открыть»; никаких загадочных «pro».
8. Ссылка рефералки — `ref_<8 символов>`, не Telegram ID. Заголовок рефералки — со склонением.
9. Онбординг: приветствие **один раз** (`POST /onboarding/complete` на «поехали»), инструкция 5 слайдов со свайпом, повторный вход из профиля **без** приветствия.
10. `avatar.jpg` (с ©) нигде не показывать — для фона только `avatar-clean.jpg` и только размытым.
11. `prefers-reduced-motion` отключает все сдвиги/масштабы (остаётся fade ≤ 120 мс).
12. SVG-заглушки — детерминированны и кэшируются; текст в них укорачивается, а не уменьшается ниже 18.
13. Баннер бота — кэшировать `file_id`; фон-фото и запасной процедурный вариант (§9).
14. Шрифты Unbounded + Inter с Google Fonts, `display=swap`, фолбэки заданы токенами.

### 10.5 Допущения и вопросы к заказчику

- «Пробный экспорт» — информационный счётчик (1 → 0 после первого готового пака), отдельной механики нет.
- Pro открывается первой покупкой генераций (допущение из PLAN) — тексты S06/S11 это объясняют; если правило изменится — поменять два экрана.
- Подсказка про telegram premium на экране «пак готов» (S14) — подтвердить формулировку.
- Юридические тексты (S12) — заглушки до материалов заказчика; имя аккаунта поддержки и бота — из конфигурации.
- Цена в ⭐, ступени скидок (≥30 → −10 %, ≥50 → фикс.) — из конфигурации; в макетах значения иллюстративные.
