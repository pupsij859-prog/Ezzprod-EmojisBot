# Готовые шрифты ника

15 шрифтов с Google Fonts (статичные .ttf с кириллицей, скачаны через fonts.googleapis.com/css2).
Список, названия и подписи — `PRESETS` в `app/user_fonts.py`; имя файла = id шрифта.

Все шрифты — SIL Open Font License 1.1 (https://openfontlicense.org): их можно встраивать и распространять
вместе с программой. Dela Gothic One урезан до латиницы и кириллицы (параметр `text=` API) — полный файл весит 2,4 МБ
из-за японских иероглифов.
