# EzzProd bot

Telegram-бот и Mini App для персональных паков эмодзи и стикеров. Повторяет механику референса @tierubot со своим брендом и оформлением.

**Этап 1 (сейчас).** Весь интерфейс и бизнес-логика работают. Шаблоны — процедурные заглушки (319 штук, категории и счётчики как у референса), а «создание пака» — имитация (прогресс → «готово»). Оплата — Telegram Stars.
**Этап 2 (дальше).** Настоящая генерация и создание наборов в Telegram. Швы под неё уже заложены (см. «Что подменять дальше»).

## Быстрый старт (Windows)

1. Создай бота у [@BotFather](https://t.me/BotFather) командой `/newbot` и скопируй токен.
2. Запусти `run.bat`. При первом запуске он создаст окружение, установит зависимости и откроет файл настроек `%LOCALAPPDATA%\EzzProdBot\.env` (он лежит вне OneDrive, чтобы токен не синхронизировался в облако).
3. Впиши `BOT_TOKEN`, свой Telegram ID в `ADMIN_IDS` и юзернейм поддержки в `SUPPORT_USERNAME`.
4. Mini App должен открываться по **публичному https-адресу** (localhost Telegram не принимает). Подними туннель, например:
   ```
   cloudflared tunnel --url http://localhost:8000
   ```
   Адрес вида `https://….trycloudflare.com` вставь в `WEBAPP_URL` (без `/` на конце).
5. Запусти `run.bat` ещё раз. В консоли появится `бот запущен: @твой_бот`.
6. Открой бота и нажми `/start`: придёт баннер с кнопкой «открыть редактор», в чате появится кнопка меню «открыть».

Если туннели Cloudflare в твоей сети заблокированы, запускай `run-public.bat`: он поднимает туннель localhost.run и бота вместе, а когда бесплатный localhost.run меняет адрес (это бывает каждые несколько минут), сам вписывает новый в `WEBAPP_URL` и перезапускает бота. Первый запуск всё равно через `run.bat`.

Бесплатный туннель cloudflared выдаёт новый адрес при каждом запуске. Для постоянного адреса нужен свой домен или хостинг. Пока бот работает на ноутбуке, при выключенном компьютере он недоступен.

## Проверка интерфейса без Telegram

В файле настроек поставь `DEV_MODE=1`, **убери `WEBAPP_URL`**, запусти `run.bat` и открой http://localhost:8000. Приложение войдёт под тестовым пользователем (другой: `?dev=2002`). Оплата в этом режиме эмулируется. Обход подписи работает только с этого компьютера и не через туннель; вместе с публичным `WEBAPP_URL` приложение откажется запускаться. Для работы в Telegram ставь `DEV_MODE=0`.

## Как это устроено

```
app/            бэкенд (FastAPI) и бот (aiogram 3) в одном процессе
  main.py       сборка приложения, запуск бота
  api/routes.py HTTP API Mini App; api/dev.py — маршруты только для DEV_MODE
  services.py   баланс (ledger), паки, рефералы, платежи, возвраты, стили
  pricing.py    цены в Stars (монотонные)
  catalog.py    каталог шаблонов; placeholders.py, preview.py — заглушки превью
  packs.py      PackBuilder (имитация сборки) и фоновый запуск
  payments.py   PaymentProvider (Stars); reconcile.py — сверка с журналом Telegram
  bot/          /start, баннер, оплата, команды, уведомления
webapp/         Mini App без сборки: ES-модули + CSS; assets/ — графика
tools/gen_bg.py генератор фоновых SVG (рельеф и хребты)
tests/          pytest
docs/           разбор референса, план, дизайн-спека, критика, ревью
```

База (SQLite) и загруженные логотипы лежат в `%LOCALAPPDATA%\EzzProdBot`. Путь печатается при старте.

### Правила, которые нельзя ломать
- Баланс меняется только через журнал `ledger` в одной транзакции. Каждое поступление денег записывается в `payment_events` с уникальным `charge_id`: повторная доставка платежа невозможна, платёж, который не сходится с заказом, уходит в `needs_review` и сообщается администратору, а не теряется.
- Если бот был выключен, `reconcile.py` на старте и каждые 15 минут сверяет платежи с `getStarTransactions` и доначисляет пропущенные.
- Подпись `initData` проверяется на каждом запросе. Реферальный код непрозрачный (`?start=ref_xxxxxxxx`), не Telegram ID. Награда за друга: +3 после его первого пака, не больше 10 в сутки и 30 за всё время.
- `POST /packs` идемпотентен по заголовку `Idempotency-Key` (повтор не списывает генерации дважды).
- Приветствие и инструкция показываются один раз: флаг `onboarded` хранится на сервере. Инструкция всегда доступна в профиле.
- Pro открывается после покупки `PRO_MIN_PURCHASED` генераций суммарно (по умолчанию 20) и даёт сохранённые стили. Это допущение: правило легко поменять.
- Цены, скидки и награды настраиваются в `.env` (блок «Экономика»).

### Деньги и правила Telegram
- Внутри Telegram цифровые товары продаются только за Stars (по Bot Developer ToS, §6.2). «Свою оплату вместо Stars» для генераций подключать нельзя; шов `PaymentProvider` оставлен для веб-оплаты вне Telegram и физических товаров. Перед запуском перечитай ToS в оригинале.
- В демо-режиме реальные счета Stars заблокированы, даже если случайно поставить `PAYMENTS_LIVE=1`. По умолчанию `PAYMENTS_LIVE=0`. Для публичного запуска сначала подключи реальную сборку и поставь `DEMO_MODE=0`.
- Возврат: администратор шлёт боту `/refund <charge_id>` (нужен `ADMIN_IDS`). Если генерации по платежу уже потрачены, автоматический возврат отклоняется.
- **Админка** в Mini App видна только `ADMIN_IDS`: статистика, платежи (возврат кнопкой, спорные `needs_review`), пользователи (поиск, ручное начисление и списание через `ledger` с пометкой «вручную»), лента паков.
- Заметка: кастомные эмодзи в сообщениях ставят подписчики Telegram Premium; интерфейс предупреждает об этом до списания генераций.

### Кастомные эмодзи в текстах
Тексты-подсказки в Mini App оформлены как цитаты Telegram и начинаются с эмодзи по ключу (`gift`, `warn`, `crown`…). Список ключей и запасные обычные эмодзи — в `app/emoji.py`. Чтобы показывать кастомные эмодзи Telegram, впиши их `custom_emoji_id` в `IDS` там же или в `.env`: `CUSTOM_EMOJI=gift:<id>,warn:<id>`. ID видно, если переслать сообщение с эмодзи боту @idstickerbot. Бот сам скачает файл один раз (нужен `BOT_TOKEN`) и сохранит в папку данных; анимированные рисуются через Lottie.
